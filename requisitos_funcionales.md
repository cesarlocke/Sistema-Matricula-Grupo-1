Rama feature/documentacion — contiene el archivo requisitos_funcionales.md con los siguientes requisitos:
•	RF1: El sistema debe permitir registrar los datos personales y académicos del estudiante.
•	RF2: El sistema debe permitir seleccionar y asignar cursos disponibles según el cupo.
•	RF3: El sistema debe generar un comprobante de matrícula en formato PDF.
•	RNF1: El sistema debe responder a las solicitudes de matrícula en menos de 3 segundos.
•	RNF2: El sistema debe ser compatible con los navegadores web Chrome, Firefox y Edge.
Rama feature/diseno — contiene el archivo diagrama_casos_uso.md, que describe:
•	Actores: Estudiante y Administrador.
•	Casos de uso: Registrar estudiante, Consultar cursos disponibles, Matricular estudiante y Emitir comprobante de matrícula.
•	Relación: el Estudiante inicia la matriculación y el Administrador valida y aprueba el registro.
