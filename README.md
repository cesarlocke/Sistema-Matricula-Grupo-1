# Sistema-Matricula-Grupo-1
Sistema de Gestión de Matrícula Estudiantil"
## Descripción
Sistema web que permite gestionar el proceso de matrícula de los estudiantes, incluyendo el registro de datos personales, la selección de cursos disponibles y la generación del comprobante correspondiente, reduciendo los tiempos de matriculación manual.
## Objetivo
Automatizar y ordenar el proceso de matrícula estudiantil mediante una plataforma que permita registrar, consultar y gestionar la información académica de forma ágil y confiable.

## Funcionalidades principales
•	Registro de estudiantes con validación de datos personales y académicos.
•	Gestión de cursos, horarios y cupos disponibles.
•	Matriculación automática con verificación de requisitos y disponibilidad.
•	Generación de reportes y comprobantes de matrícula en PDF.
